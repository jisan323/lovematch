## 🚀 Deploying to Vercel (1-Click Setup)

This repository is pre-configured for instant zero-configuration deployment on **Vercel**.

### Step 1: Import Repository to Vercel
1. Go to [Vercel Dashboard](https://vercel.com/dashboard) and click **"Add New..." → "Project"**.
2. Connect your GitHub account and select your repository: `lovematch`.

### Step 2: Build & Output Settings
Vercel will automatically detect `Vite` through `vercel.json`. The default settings are:
- **Framework Preset**: `Vite`
- **Root Directory**: `./`
- **Build Command**: `npm run build`
- **Output Directory**: `dist`
- **Install Command**: `npm install`

### Step 3: Deploy!
Click **"Deploy"**. Your application will be live in ~30 seconds with a free `.vercel.app` domain and global edge CDN.
